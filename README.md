# Exploratory Indigenous Language Similarity Analysis in Bangladesh

### A Word2Vec-Based Study of Language Similarity and Potential Family Recovery


## Overview

This project explores potential similarity patterns among eight Indigenous languages of Bangladesh using Word2Vec embeddings, cosine similarity, hierarchical clustering, and a lexical edit-distance baseline. Bangla and English are included as reference languages.

The analysis is exploratory. Computational similarity alone cannot establish linguistic ancestry or definitively classify languages into language families.

## Languages

- **Indigenous languages:** Chakma, Marma, Garo, Kokborok, Santali, Khasi, Mro, and Hajong
- **Reference languages:** Bangla and English

## Methodology

The project follows a five-stage pipeline to explore linguistic similarity and potential family relationships among eight Indigenous languages of Bangladesh.

**1. Dataset Collection and Preprocessing:**  
A parallel corpus was collected through web scraping from MultiLing Cloud. The dataset was cleaned by removing invalid or incomplete records, standardizing text, and eliminating duplicates, resulting in 5,842 records.

**2. Corpus Construction and Word Embedding:**  
The eight Indigenous languages were combined with deduplicated Bangla and English sentences to construct a shared training corpus. Skip-gram and Continuous Bag of Words (CBOW) Word2Vec models were trained from scratch using 100-dimensional embeddings.

**3. Language Representation and Similarity Analysis:**  
Sentence vectors were generated by averaging their constituent word embeddings. Language-level vectors were then constructed by averaging sentence vectors for each language. Cosine similarity was used to calculate pairwise similarities and generate language similarity matrices.

**4. Hierarchical Clustering and Baseline Comparison:**  
Agglomerative hierarchical clustering with average linkage was applied to the eight Indigenous languages using cosine distance. The number of clusters was evaluated across k = 2–6 against known language-family labels. A normalized Levenshtein edit-distance baseline was also used for comparison.

**5. Validation and Reproducibility Analysis:**  
The clustering results were evaluated using the Adjusted Rand Index (ARI) and a permutation test. Mantel tests examined the relationship between embedding distances and character-trigram surface-overlap and geographical distances. Multi-seed reproducibility experiments and sentence-level translation retrieval tests were also conducted to assess the reliability of the results.

The overall pipeline compares Skip-gram and CBOW while examining whether the observed similarity patterns reflect potential linguistic relationships or are influenced by surface-level overlap and training instability.

## Results

### 1. Clustering Performance

The clustering performance of Skip-gram and CBOW was evaluated
using the Adjusted Rand Index (ARI) against three known language
families.

| Method | ARI | Observation |
|---|---:|---|
| Skip-gram | 0.6067 | Sensitive to training conditions |
| CBOW | 0.6067 | Stable across evaluated conditions |
| Lexical edit-distance baseline | 0.3000 | Baseline comparison |

Although both embedding models achieved the same ARI in the
reported main experiment, reproducibility analysis showed that
Skip-gram was more variable across training conditions.

### 2. Reproducibility Analysis

The analysis included 39 logged observations per model, pooled
across the evaluated training conditions.

| Training Setting | Skip-gram (Mean ± SD) | CBOW (Mean ± SD) |
|---|---:|---:|
| Multi-thread | 0.57 ± 0.12 | 0.607 ± 0.000 |
| Single-thread, Run 1 | 0.27 ± 0.12 | 0.607 ± 0.000 |
| Single-thread, Run 2 | 0.24 ± 0.00 | 0.607 ± 0.000 |

CBOW remained consistent under the evaluated conditions, whereas
Skip-gram exhibited greater variability. These findings support
the use of reproducibility checks when evaluating embeddings
trained on low-resource language data.

### 3. Language Similarity

The reported analysis identified the following highly similar
language pairs:

| Model | Closest Indigenous-Language Pair | Similarity |
|---|---|---:|
| Skip-gram | Garo–Mro | 0.98 |
| CBOW | Marma–Khasi | 0.97 |

These similarities describe the learned embedding representations
and should not be interpreted as definitive evidence of common
linguistic ancestry.

### 4. Surface-Overlap Validation

Mantel tests showed a strong correlation between embedding
distances and character-trigram surface-overlap distances.

| Model | Mantel Correlation (r) | Reported p-value |
|---|---:|---:|
| Skip-gram | 0.84 | < 0.001 |
| CBOW | 0.82 | < 0.001 |

These results suggest that orthographic or phonetic overlap may
account for a substantial portion of the observed similarity
structure.

Geographical analysis remains pending verification of the
coordinates used in the analysis.

## Limitations

- **Small and uneven corpora:** Each Indigenous language has a limited number of records, and corpus sizes differ across languages. With `min_count = 1`, rare words may have poorly estimated embeddings.
- **Text preprocessing:** Unicode handling, transcription conventions, duplicates, and orthographic differences can affect similarity. Preprocessing must preserve the scripts used by the included languages.
- **Cross-language comparability:** Training in a shared space does not automatically make all cross-language vectors semantically aligned. Shared scripts, transliteration, paired Bangla/English reference text, and overlapping surface forms may inflate some similarities.
- **Language-level aggregation:** Averaging word vectors can hide variation within a language and depends on which words are included and how they are weighted.
- **Genealogical claims:** Similarity and clustering are exploratory signals, not proof of language-family membership.
- **Geographical analysis:** Geographic results should not be interpreted until the coordinates are verified.
- **Reproducibility:** The raw dataset is not public, so the repository alone is insufficient to reproduce every reported numerical result.

## Future Work

- Validate findings with linguistic experts and trusted linguistic classifications.
- Improve Unicode-aware preprocessing and verify text normalization.
- Compare against character-level and multilingual embedding baselines.
- Test clustering stability across seeds and cluster counts.
- Increase and balance the corpus where reliable data are available.
- Verify geographic metadata before conducting geographic comparisons.
- Evaluate results on independently collected data.

## Reproducibility

The main analysis script is `ids_project.R`. To rerun the analysis, prepare the input dataset locally and update the script's input path as needed. The raw dataset is not included in this repository, so results cannot be reproduced from the public repository alone.
